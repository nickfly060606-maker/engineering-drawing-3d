# 三视图判读规则与参数提取

面向工程制图复习题（组合体、截交线、相贯线、补画第三视图）。目标不是「看出像什么」，而是把每条线对应到形体上的一个面或一条棱，并把尺寸归一化，交给反投影校验。

## 1. 投影对应（三等关系）

| 关系 | 含义 | 用途 |
|---|---|---|
| 长对正 | 主视图与俯视图的 x 坐标一致 | 俯视图里某条竖线的 x，直接就是主视图里某个面的 x |
| 高平齐 | 主视图与左视图的高度一致 | 主视图斜线的起止高度，必须与左视图弧线的高度范围一致 |
| 宽相等 | 俯视图的深度与左视图的水平宽度对应 | 俯视图的 y 范围 ↔ 左视图的 x 范围 |

线型：
- **粗实线** = 可见轮廓，构成实心区域的边界。
- **虚线** = 不可见轮廓（被前方/上方材料遮挡的面），**但不改变外轮廓**。
- **点画线** = 中心线/对称线，浅灰，**不参与形体**。提取实心区域时必须排除，否则 flood fill 会把区域切成两半。

## 2. 判读顺序

1. **定主体**：俯视图是完整圆 → 回转体（圆柱/圆锥/球）；俯视图是矩形 → 棱柱；俯视图由多个矩形拼接 → 组合体。
2. **找切割**：斜线 → 平面切割；圆弧/椭圆弧 → 柱面、锥面或相贯线；阶梯状折线 → 台阶面。
3. **判遮挡**：虚线出现在某个视图内部，说明该面被别的材料挡住；结合另外两个视图判断挡它的是上方还是前方。
4. **逐线归位**：给每条非轮廓线写出「它是哪个面在哪一层的投影」。写不出来就说明形体还猜错了。

## 3. 高频对应关系（判错用）

| 现象 | 结论 / 校验式 |
|---|---|
| 主视图一条斜线 + 左视图一条椭圆弧 | 同一个斜切面。斜线斜率 ≈ 椭圆弧半轴比，两者必须互证 |
| 俯视图完整圆 + 一条竖直虚线 | 至少有一层仍是完整圆柱；虚线是 x = 常数 的遮挡面，**外轮廓不缩小** |
| 左视图中部收窄 | 该高度处只剩一片薄壁。收窄宽度应 ≈ `2*sqrt(R² − x²)`，x 取俯视图虚线位置 |
| 俯视图外轮廓不再是圆 | 说明圆柱被削到最底层，与「完整圆」互斥，需要重新解 |
| 主视图出现台阶 + 俯视图对应位置有虚线 | 台阶面在某个高度区间存在，上下两段仍是完整截面 |
| 相贯线（两圆柱相交） | 是空间曲线，三视图里都表现为弧；需密集采样求交，不要用直线近似 |

**任何一条对不上，就回到形体假设，不要继续建模。** 上一道题之所以判定为「圆柱 + 斜切 + 台阶」而不是「圆柱被削掉一块」，正是因为俯视图外轮廓仍是完整圆。

## 4. 从像素提取归一化参数

`inspect_views.py` 的 `meta.json` 给出每个视图的包围盒、宽高比和 21 条扫描线的水平区间（相对包围盒宽度归一化 0–1）。用法：

- 以半径 R = 1（或最长边 = 1）为基准，总高 H 由主视图宽高比给出；
- 台阶位置 x = 扫描线区间端点的平均值换算到 [−1, 1]；
- 斜线斜率 = 起点与终点的 (Δ高度 / Δ水平)，高度用主视图比例、水平用俯视图直径换算；
- 收窄处宽度 / 直径 → 换算成 x = `sqrt(1 − (w/2)²)` 与虚线位置比对。

把结果写成一句话参数表，例如：

```
R = 1, H = 2.09R
台阶面 x = 0.609R, 高度 z ∈ [0.180H, 0.449H]
斜切面 z: 0.449H → 0.888H，同时 x: 0.609R → −R（倾角约 30°）
```

### 4.1 提取脚本的噪声处理（非显然，别改错）

`inspect_views.py` 先按「粗实线」求障碍、再从图片边界 flood fill 求实心区域，最后**保留所有主要连通块**（面积 ≥ 总实心像素 0.5% 且 ≥ 80 px），只丢掉题号文字之类的小碎点。

**不要改成「只保留最大连通块」。** 视图内部的实线分界线（半圆弧、水平棱线、水平中心线）会把实心区域切成多块：实测那道题的俯视图被切成 2 块、左视图被切成 8 块，只取最大块会丢掉半个圆。实测正确结果：

```
front: 1 个连通块  180×188  宽高比 0.9574
top:   2 个连通块  180×181  宽高比 0.9945   ← 完整圆
left:  8 个连通块  179×187  宽高比 0.9572
```

三个视图的直径同为 180 px，正好满足「长对正、宽相等」，可作为提取是否正确的数值自检。若某视图 bbox 贴到裁剪框边缘，脚本会打印警告，此时用 `--regions` 放宽该框重跑。

### 4.2 内部棱线不是空隙

视图内部的实线（棱线、弦、相贯线）和点画中心线只是**分界标记**，不是形体上的缝。但掩码提取会把它们当成障碍，留下白色细缝，且这些缝大多**贯通到视图边界**（例如俯视图那条从圆周左端连到右端的水平弦）。

- 后果：直接拿去求视觉外壳，模型会被切成几块；反投影吻合度掉到 0.96 左右；手性自动判别也可能选错。
- 处理：`auto_reconstruct.py` 先做形态学闭运算（n=2）填贯通细缝，再 `fill_holes` 补封闭小洞。
- 不要试图用「只保留最大连通块」来绕开，那会丢掉半个圆（见 4.1）。

### 4.3 自洽的假阳性：方向错误查不出来

三张掩码若被统一转置 90°，视觉外壳仍然自洽，吻合度照样能到 0.978，但重建出的是完全错误的形体。**数值指标无法发现这类错误**。

因此 `compare.png` 上排固定贴 `inspect_views.py` 产出的原始裁剪图（未做任何变换），下排才是重建投影。每次交付前先肉眼确认上排三张图的摆放方向正确：主视是竖向轮廓、俯视是圆、左视是 L 形。

## 5. 完整例题（2026-11-09，第 2 题「补画左视图」）

原题：主视图是带左上缺口、中部斜线、底部小凸台的轮廓；俯视图是完整圆 + 一条竖直虚线；左视图（学生补画，品红色）上部宽、中部收窄、下部又变宽，内部有半圆弧。

推理链：

1. 俯视图完整圆 → 底部和顶部都存在完整圆柱层，只是中间某段被切。
2. 俯视图竖直虚线 x ≈ 0.61R → 中段存在一个平面 x = 0.61R，被上方圆柱遮挡，所以画虚线。
3. 主视图那条斜线斜率 0.57，从 x = 0.61R、z = 0.449H 升到 x = −R、z = 0.888H → 这是一个斜平面，越往左切得越浅。
4. 左视图的椭圆弧就是该斜平面与圆柱面的交线。实测半轴比 0.55 ≈ 斜率 0.57，两个视图互相印证。
5. 左视图中部宽度 1.66R ≈ 圆在 x = 0.61R 处的弦长 1.59R（误差在描边宽度内）→ 中段确实只剩右侧薄壁。
6. 因此学生补画的「上宽—中窄—下宽」是对的，不是画错。

结论形体：**竖直圆柱，左上部被约 30° 斜面切掉一大块，中段只剩右侧一片薄壁相连；切口朝左下，标准右前上方视角看不见，必须提供仰视。**

## 6. 常见误判

- 把「完整圆 + 虚线」当成「圆柱被削掉一块」→ 外轮廓会错。
- 把斜切面的椭圆弧当成「半圆孔」→ 会凭空多出一个孔。
- 把点画中心线算进实心区域 → 掩码被切成两半，参数全错。
- 只看主视图就下结论 → 必须三视图同时满足，反投影校验是唯一硬标准。
